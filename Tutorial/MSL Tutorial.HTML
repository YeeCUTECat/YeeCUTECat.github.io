MSL 开服器完整新手教程

零基础学会搭建Minecraft服务器

想必你也曾羡慕可以使用插件、模组的Minecraft服务器，但自己从零搭建对新手来说门槛很高，很多人因此放弃。本篇教程带你从零使用 MSL开服器 一键搭建属于自己的服务器。

教程初衷：希望更多优质小众服务器出现，请勿使用本教程搭建快餐盈利服务器！

1 下载 MSL 开服器

两种下载渠道可选：

  • 浏览器搜索关键词：MSL开服器
  • 官方直达链接：https://www.mslmc.cn/

进入官网后，页面会显示下载按钮，点击「立即下载」获取软件安装包。

2 添加服务器

打开安装完成的MSL软件，先阅读并同意软件用户协议，进入软件主界面。

2.1 创建服务器实例

软件无服务器实例时，页面会显示「添加服务器」按钮，点击界面 + 加号按钮新建实例。

创建模式分为两类：

  • 快速模式：服务器文件自动存放至MSL软件目录，适合纯小白
  • 自定义模式：自定义服务器存储路径，适合有基础的用户，新手可忽略

整合包模式本篇暂不讲解。

2.2 服务器类型选择

MSL支持全类型Minecraft服务端，可选分类：

  • 插件服务器（Paper/Spigot/Bukkit/Folia/Purpur/Sponge）
  • 插件模组混合服务器（Forge/NeoForge / Fabric）
  • 纯模组服务器（Forge/NeoForge / Fabric）
  • 原版纯净服务器
  • 代理服务器
  • 基岩版服务器

使用建议：

  • 只玩原版无插件：选择「原版服务器」
  • 需要安装插件：选择「插件服务器」，加载器默认 Paper 无需修改

选择对应游戏版本后，软件会自动高速下载对应服务端核心文件；下载完成后选择控制台模式，指令不熟悉推荐「伪终端」，完成实例创建。

2.3 启动服务器

创建完成后列表会出现默认名为 Myserver 的服务器实例，点击实例进入控制面板。

首次启动会弹出Mojang官方EULA许可协议，协议地址：https://www.minecraft.net/zh-hans/eula，点击「是」同意协议即可启动服务器，下次启动无需重复确认。

3 进入服务器游玩

不是单人世界开局域网，操作步骤：

  1. 打开你的Minecraft客户端，点击「多人游戏」
  2. 点击「添加服务器」
  3. 服务器地址填写本地端口：127.0.0.1:25565
  4. 服务器名称可自定义，留空默认显示「A Minecraft Server」
  5. 选中服务器条目，点击进入游玩

3.1 登录报错解决方案

报错场景：非正版账号无法连接服务器
  1. 先关闭正在运行的服务器
  2. 打开对应服务器实例的「实例设置」
  3. 找到配置项 Online-mode，将值从 true 修改为 false
  4. 保存设置后重新启动服务器，即可使用离线账号登录

额外指令：服务器默认关闭死亡不掉落，在游戏内聊天框输入指令开启：
/gamerule keep_inventory true
